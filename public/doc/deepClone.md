# deepClone

深度克隆一个对象，包括：

- 普通对象和数组
- `Date`、`RegExp`、`Map`、`Set`
- 支持循环引用

## 参数

| 参数名 | 类型      | 描述                                     |
| ------ | --------- | ---------------------------------------- |
| `obj`  | `T`       | 要克隆的原始对象                         |
| `hash` | `WeakMap` | 用于处理循环引用的缓存映射，默认自动维护 |

## 返回值

返回对象的深克隆副本。
