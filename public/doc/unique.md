# unique

## 函数声明

```typescript
function unique<T>(arr: T[]): T[];
```

## 描述

`unique` 函数用于移除数组中的重复元素。

## 参数

| 参数名 | 类型   | 描述           | 默认值 |
| ------ | ------ | -------------- | ------ |
| `arr`  | `T[]`  | 需要去重的数组 | —      |

## 返回值

`T[]` — 返回去重后的新数组。

## 使用示例

### 基本用法

```typescript
unique([1, 2, 2, 3, 3, 3]);
// 输出: [1, 2, 3]

unique(["a", "b", "a", "c"]);
// 输出: ["a", "b", "c"]
```

### 混合类型

```typescript
unique([1, "1", 1, true, true]);
// 输出: [1, "1", true]
```
