# flatten

## 函数声明

```typescript
function flatten<T>(arr: any[], depth?: number): T[];
```

## 描述

`flatten` 函数用于将多维数组转换为一维数组。支持指定扁平化的深度。

## 参数

| 参数名  | 类型     | 描述                     | 默认值      |
| ------- | -------- | ------------------------ | ----------- |
| `arr`   | `any[]`  | 需要扁平化的数组         | —           |
| `depth` | `number` | 扁平化的深度             | `Infinity`  |

## 返回值

`T[]` — 返回扁平化后的新数组。

## 使用示例

### 完全扁平化

```typescript
flatten([1, [2, [3, [4]]]]);
// 输出: [1, 2, 3, 4]
```

### 指定深度

```typescript
flatten([1, [2, [3, [4]]]], 2);
// 输出: [1, 2, 3, [4]]

flatten([1, [2, [3]]], 1);
// 输出: [1, 2, [3]]
```
