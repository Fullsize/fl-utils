# add

## 函数声明

```typescript
function add(a: number, b: number): number;
```

## 描述

`add` 函数用于精确的加法运算，避免 JavaScript 浮点数精度问题。

## 参数

| 参数名 | 类型     | 描述     | 默认值 |
| ------ | -------- | -------- | ------ |
| `a`    | `number` | 第一个加数 | —      |
| `b`    | `number` | 第二个加数 | —      |

## 返回值

`number` — 返回两个数相加的精确结果。

## 使用示例

```typescript
add(0.1, 0.2);  // 输出: 0.3（而非 0.30000000000000004）
add(1, 2);      // 输出: 3
add(-1, 1);     // 输出: 0
```
