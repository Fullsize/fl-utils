# chuck

## 函数声明

```typescript
function chuck<T>(list: T[], size?: number): T[][];
```

## 描述

`chuck` 函数用于将给定的数组拆分成多个小数组。

## 参数

| 参数名 | 类型     | 描述                   | 默认值 |
| ------ | -------- | ---------------------- | ------ |
| `list` | `T[]`    | 要拆分的数组           | —      |
| `size` | `number` | 每个小数组的长度       | `2`    |

## 返回值

`T[][]` — 返回一个由拆分后的小数组组成的二维数组。

## 使用示例

```typescript
chuck([1, 2, 3, 4, 5]);       // 输出: [[1, 2], [3, 4], [5]]
chuck([1, 2, 3, 4, 5], 3);    // 输出: [[1, 2, 3], [4, 5]]
chuck([1, 2], 5);             // 输出: [[1, 2]]
```
