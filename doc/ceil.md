# ceil

## 函数声明

```typescript
function ceil(number: number, precision?: number): number;
```

## 描述

`ceil` 函数用于对一个数值进行向上取整处理。你可以指定保留的小数精度位数，默认精度为 0，即取最接近且大于或等于原数的整数。

## 参数

| 参数名      | 类型     | 描述                         | 默认值 |
| ----------- | -------- | ---------------------------- | ------ |
| `number`    | `number` | 要向上取整的原始数值         | —      |
| `precision` | `number` | 精度，表示小数点后保留的位数 | `0`    |

## 返回值

`number` — 返回向上取整后的数值，保留指定的小数位数。

## 使用示例

### 默认精度

```typescript
ceil(4.2);   // 返回 5
ceil(-4.2);  // 返回 -4
```

### 指定精度

```typescript
ceil(6.004, 2);     // 返回 6.01
ceil(123.0001, 3);  // 返回 123.001
ceil(-3.1415, 2);   // 返回 -3.14
```

## 注意事项

- 与 `Math.ceil` 不同，该函数支持对小数点后多位进行精度控制。
- 精度为负数时的行为未定义，如有需要建议自定义扩展。
